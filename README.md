## 🧑‍💻 About Me

<img align="right" width="320" src="https://user-images.githubusercontent.com/74038190/212284100-561aa473-3905-4a80-b561-0d28506553ee.gif" />

I'm an **Information Technology** student at **Shah & Anchor Kutchhi Engineering College (SAKEC), Mumbai**, currently building real-world software that mixes web development, data analytics, and applied AI.

I like projects that actually *do something* — an app that reads your electricity bill and explains it in plain language, a dashboard that turns raw agricultural data into recommendations, a hospital system that ties records to a working dashboard. I care less about stacking buzzwords and more about shipping something that runs end to end.

- 🌱 Currently deepening my **DSA, SQL, and cloud fundamentals**
- 🤖 Exploring how **LLMs and RAG** can be grounded in real, verifiable data instead of hallucinated output
- 📊 Enjoy turning messy datasets into dashboards people can actually use
- 🏆 Actively participating in **hackathons** and solo/team academic projects
- 💬 Ask me about **Flask, Power BI, or AI-assisted app design**
